# 📦 Raw Materials Team - Quick Reference

## Daily Tasks

### Check Stock Levels
1. Go to **Raw Materials** page
2. Review KPI cards at top:
   - 🔴 **Out of Stock** - Order immediately
   - 🟡 **Low Stock** - Plan reorder
3. Filter by category if needed

### Receive Goods (GRN)
1. **Goods Received** → **+ Create GRN**
2. Select **Supplier** and **Warehouse**
3. Add each material received:
   - Material name
   - Ordered vs Received qty
   - Unit cost
   - Batch number
4. Submit → Await approval

### Quality Check
1. **Quality Inspection** → **+ Create Inspection**
2. Select the **GRN** and **Material**
3. Enter test results (moisture, protein, etc.)
4. Mark as **Passed** or **Failed**

---

## Status Guide

| Badge | Meaning | Action |
|-------|---------|--------|
| 🟢 In Stock | Good | None |
| 🟡 Low Stock | Below reorder | Plan purchase |
| 🔴 Out of Stock | Zero | Urgent order |
| 🟠 Pending | Awaiting approval | Wait |
| 🟢 Approved | Confirmed | Stock updated |
| 🔴 Rejected | Not accepted | Review reason |

---

## Common Issues

**Can't find material?**
→ Use search bar or check category filter

**GRN rejected?**
→ Check rejection reason in details, create new GRN

**Stock not updated after GRN?**
→ GRN must be Approved first
